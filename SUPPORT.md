# Support

## Scope

This repository is an internal developer-environment utility. Support is limited to installation, diagnostics, updates, repair routines, and repository maintenance.

## Before reporting a problem

1. Confirm the operating system and version.
2. Run the available validation or doctor command.
3. Capture the exact command, output, and expected behavior.
4. Remove credentials, tokens, private URLs, and personal data.

## Reporting

Open a GitHub issue with a clear title and reproducible steps. Include logs only when they are safe to share.

Security vulnerabilities must follow `SECURITY.md` and must not be disclosed in a public issue.
