# HYBRID Developer Kit

Kit oficial para preparação, validação e diagnóstico dos ambientes de
desenvolvimento da HYBRID Tecnologia Inteligente.

> Status: fundação inicial. O instalador completo ainda não está disponível.

## Objetivo da v0.1.0

A primeira versão será focada em:

- Linux Mint;
- Ubuntu;
- Debian;
- perfil do Hercules Pet Platform.

## Funcionalidades planejadas

- detectar o sistema operacional;
- instalar e validar Git;
- instalar e validar GitHub CLI;
- instalar Docker e Docker Compose;
- instalar Node.js e pnpm;
- instalar VS Code opcionalmente;
- instalar Codex CLI opcionalmente;
- configurar o Git;
- preparar o Hercules Pet Platform;
- oferecer modo `--dry-run`;
- oferecer diagnóstico com `doctor`;
- produzir relatório final;
- permitir execução idempotente.
