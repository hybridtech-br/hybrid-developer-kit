# Security Policy

## Supported versions

Security fixes are applied to the latest release and the active development branch.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| `main` | Yes |
| Older releases | Best effort |

## Reporting a vulnerability

Do not open a public issue for suspected vulnerabilities.

Report the issue privately to the HYBRID Tecnologia Inteligente maintainers through an authorized private communication channel. Include:

- affected component and version;
- operating system and environment;
- reproduction steps;
- impact assessment;
- logs or evidence with secrets removed;
- suggested mitigation, when available.

Do not include credentials, tokens, private keys, customer data, or production secrets.

## Response process

The maintainers will validate the report, assess severity, coordinate remediation, and publish a disclosure when appropriate. Timelines depend on reproducibility, impact, and release risk.

## Scope

This policy covers the HYBRID Developer Platform source code, installation scripts, CI workflows, manifests, profiles, and official release artifacts.
